# Architecture Decision Records

Architecture Decision Records (ADRs) capture durable choices that constrain implementation.

| ADR | Decision | Status |
| --- | --- | --- |
| [0001](0001-public-api-first-native-overlays.md) | Public-API-first native overlays | Accepted |
| [0002](0002-classic-plugin-split-ready-boundaries.md) | Classic plugin with split-ready boundaries | Accepted |
| [0003](0003-single-clock-motion-budget.md) | Single active-only clock and hard motion budgets | Accepted |

New ADRs use four-digit sequence numbers and include context, decision, alternatives, consequences, and reconsideration triggers. Do not edit an accepted decision to reverse it; add a superseding ADR.
